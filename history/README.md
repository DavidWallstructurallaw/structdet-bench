# Historical evidence archive

This directory is outside normal `unittest` discovery. It contains no active
verification runner. The complete original development evidence is retained in
`StructDet-Bench_Phase4_Step3_Local.zip`, carried once in the enclosing delivery's
`history/` directory. That immutable package contains the original Phase 1 to 4
runners, exact tests, matrices, journals, failed attempts, handoff identities and
nested predecessor deliveries. Earlier completion documents remain in the source.

For a historical audit, extract the identified original package into a separate
workspace and use its original runtime and instructions. Historical runners are
not supported against the current source tree. Their former source paths are
intentionally absent from the active tree rather than maintained as forwarding
wrappers. Nothing in the current runner reinterprets an earlier execution receipt.

Some phase-named helper files remain because current scientific fixtures import
shared builders, source references or pure utilities. Historical matrices and
metadata remain readable archival material. They do not select current tests,
certify current completion, or supply a minimum method count. See
`../VERIFICATION.md` for the retained-behavior mapping and consolidation limits.
