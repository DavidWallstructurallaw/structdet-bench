identity and scoped evidence records, constructs the selected realization
inventory, calculates the approved finite-sample structural quantities, and
publishes a new JSON/Markdown report set with an input/software/output manifest.

| Prefixes | Prespecified order without backfill, both views, accumulation grid, and the separate HERO complete-intended-group checks for k=5,10,20. |
| Output | Common JSON/Markdown meaning, explicit unavailable and deferred results, scoped provenance, protected private text, reproducible canonical reports and no-overwrite publication. |

Threshold comparisons use the full accepted denominator and exact decimal/integer
comparison. Counts and memberships remain exact. Derived metrics use unrounded
values. Numerical checks apply the approved absolute `1e-12` plus relative `1e-10`
convention, with recorded representational boundary corrections and explicit
withholding for material failures. Empty distributions, absent observations,
unknown frames and genuine one-class concentration retain distinct outcomes.

This is a first measurement instrument for the adopted bounded-integer sorting
frame and imported hard assignments. Its registry has eight defined mechanisms;
that inventory is neither an exhaustive algorithm ontology nor independently
validated model support. An unresolved mechanism remains reviewable without
