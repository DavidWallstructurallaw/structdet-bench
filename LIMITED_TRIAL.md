# Limited real-material trial

Completed 2026-09-23 UTC. The owner accepted this scope for software closeout;
additional sample collection is optional. The full registered empirical study
and independent validation remain pending.

## Material and actual observations

Five numbered programs were visually transcribed from six user-supplied
screenshots of model output and its interface. The saved UTF-8/LF transcriptions
were checked against the visible code. Original response bytes, the actual
submitted prompt, generation time, temperature, seed and exact backend identity
were unavailable. The five programs remain one submitted batch and are not
treated as five independent model calls.

An external bounded execution harness applied the existing HERO §5.3 input
definition to each saved program. All five completed all 8,995 inputs:
**44,975 candidate-input executions, 44,975 passes, zero failures**. Each input
checked a fresh ordinary list, ordinary integer elements, unchanged length,
nondecreasing order, preserved multiplicities and an unchanged caller input.
The input list was materialized after receipt of the screenshots. This supplies
finite functional observations, without claiming prospective review, exhaustive
domain proof or independently validated execution containment.

| Candidate | Provisional mechanism | Passed inputs |
| --- | --- | ---: |
| 1 | SORT-COUNT: full-key counting | 8,995 |
| 2 | SORT-MERGE: recursive splitting and merge | 8,995 |
| 3 | SORT-RADIX: stable digit passes | 8,995 |
| 4 | SORT-PIVOT: pivot partition and recursion | 8,995 |
| 5 | SORT-HEAP: maintained heap and root extraction | 8,995 |

These are AI-assisted proposed labels. Structural assignment and validity
adjudication, independent human review and full HERO condition comparisons were
not completed. The trial establishes no model frequency, temperature effect,
longitudinal convergence or theory-validation result.

## Toolkit behavior

StructDet-Bench 0.1.0 successfully validated and analyzed the passive intake.
Its formal records retained unresolved/provisional assignments and withheld
validity. Both admitted classification populations were empty, with
`support: 0`, the `empty_classified_population` qualifier and undefined SCI.
That zero describes the admitted population, not an absence of structure in the
submitted code. Arithmetic conditional on accepting the five proposed labels
was stored separately and did not override the formal admission state.

The toolkit itself did not execute candidates. The external harness's 44,975
candidate calls remain distinct from CLI processing. No runtime implementation,
schema, numerical definition or canonical test was changed for this trial.
